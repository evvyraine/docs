description: "Put Skye on a computer you control."

---

Skye can run on a computer you own. Keep that computer on. She only answers while it is running.

<Steps>
  <Step title="Make a Telegram bot">
    Talk to [@BotFather](https://t.me/BotFather). Copy the token he gives you.
  </Step>
  <Step title="Install Docker">
    Install Docker on the machine that will stay on.
  </Step>
  <Step title="Copy the project">
    Clone [skye-next](https://github.com/evvyraine/skye-next). Copy `.env.example` to `.env`. Put in the bot token, your Telegram user id, and an OpenAI key.
  </Step>
  <Step title="Start it">
    Run `docker compose up -d` in that folder.
  </Step>
</Steps>

Keep secrets in `.env`. Do not paste them into chat.
