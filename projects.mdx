A project is its own conversation with its own history and, if you want, its own instructions. Use one per client, per topic, or per kind of work.

## In Telegram

Open `/projects` to see and switch projects.

- **Skye** is the default project and is always there.
- **New project.** Give it a name and an emoji, and optionally some instructions. Instructions apply only to that project.
- **Switch.** The active project receives your next messages.
- **Reset.** Starts the project's conversation over and keeps the project and its instructions.
- **Delete.** Removes the project and its conversation.

Example instructions:

- "Answer in Russian, briefly."
- "You are helping with a novel. Keep a careful, neutral tone."
- "Always return amounts in euros."

<Note>
Projects are private and live in direct chats, not in groups.
</Note>

## In the browser

When the web chat is enabled, [chat.skye-bot.com](https://chat.skye-bot.com) shows the same projects with a few extras:

- a list you can pin, rename, recolour, and icon;
- streaming answers and a search field;
- file uploads with image thumbnails;
- dictation for voice input;
- reset and stop for the current project.

Sign in with Telegram. The same account drives both the bot and the web chat, and each project keeps its own conversation.

## Keeping a thread useful

| Command | What it does |
| --- | --- |
| `/catchup` | A short summary of the current thread. |
| `/reset` | A clean conversation in the current project. |
| `/stop` | Cancel the running task. |
