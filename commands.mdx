Most of the time you just write to Skye. These commands are shortcuts.

| Command | What it does |
| --- | --- |
| `/start` | Begin, or open the main menu. Also installs a shared agent when opened from a share link. |
| `/help` | What she can do, and useful links. |
| `/account` | Plan, Telegram Stars, and cancellation (private chat). |
| `/settings` | Reasoning, agent, connectors, skills, memory, automations, and projects. |
| `/projects` | Switch and manage project chats (private chat). |
| `/agents` | Create, install, select, and share agents. |
| `/catchup` | Summarise this conversation. |
| `/reset` | Start a new conversation. Memory is kept. |
| `/stop` | Cancel the active task. |
| `/admin` | Allow or ban people and groups (owner only). |
| `/paysupport` | Help with a Stars purchase. Not in the command menu. |
| `/terms` | The Skye plan terms. Not in the command menu. |

## Settings, by section

**Settings** gathers the controls a chat can change:

- **Reasoning** — how much thinking effort she spends. Higher is slower and more careful.
- **Agent** — pick the active agent or add one.
- **Connectors** — apps and custom MCP servers.
- **Skills** — uploaded skill bundles.
- **Memory** — turn memory on or off, and delete everything saved here.
- **Automations** — scheduled and webhook tasks.
- **Projects** — project chats (private only).

<Note>
In a group, only administrators can change settings. Everyone can still talk to Skye.
</Note>
