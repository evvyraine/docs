Подбирать формулировки не нужно. Скажите своими словами — остальное Skye сделает сама. Ниже — реальные по духу разговоры. Запросы специально короткие.

## Голосовое превращается в план

Пришлите сбивчивое голосовое — получите план, по которому можно жить.

<ChatDemo
  turns={[
    { from: "you", kind: "voice", text: "«Так, на неделю: доделать презентацию, записаться к врачу, выбрать подарок маме и не забыть про квартальный отчёт.»", seconds: 13 },
    { from: "sky", text: "Вот неделя, которую реально выдержать:\n\nпн–вт — презентация\nср — квартальный отчёт\nчт — врач\nпт — подарок маме" },
    { from: "sky", kind: "file", name: "план-недели.md", meta: "markdown · 2 КБ" },
  ]}
/>

## Скриншот, прочитанный за секунды

Пришлите фото или скриншот и задайте вопрос по существу.

<ChatDemo
  turns={[
    { from: "you", kind: "image", tone: "slate", caption: "чек.jpg" },
    { from: "you", text: "Какая тут итоговая сумма и нет ли ошибки?" },
    { from: "sky", text: "Итог — 148,20 €. Две строки посчитаны дважды — третья и четвёртая, — так что должно быть 96,40 €. Написать короткое письмо на возврат?" },
  ]}
/>

## Документ становится решениями и рисками

Долгие файлы превращаются в то немногое, по чему нужно действовать.

<ChatDemo
  turns={[
    { from: "you", kind: "file", name: "договор-поставки.pdf", meta: "PDF · 24 страницы" },
